# front-ocso-nest

El front de un software de gestión de un OCSO.

## Getting Started

Este proyecto está desarrollado con Next.js.

Para iniciar el servidor de desarrollo, ejecuta:

```bash
npm run dev
```

Abre http://localhost:3000 en tu navegador para visualizar la aplicación.

Puedes comenzar a editar la página modificando el archivo `app/page.tsx`. Los cambios se reflejarán automáticamente.
